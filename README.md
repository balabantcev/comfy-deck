# comfy-deck

Скілл для створення й переоформлення презентацій COMFY у **Codex, Claude, Cowork і Claude Code**. Підтримує PowerPoint та роботу з нативними Google Slides, коли середовище має відповідні підключені інструменти.

Поточна версія: **1.2.0**.

Скілл містить правила брендбуку 2026, оригінальні логотипи та каталог посилань на шрифти й графіку. **Arial Black і Montserrat залишаються основними**. COMFY Semi-Bold, Bold та Ultra-Condensed — додаткові шрифти для доречних брендових повідомлень і акцентів.

## Встановлення

### Claude, Claude Desktop і Cowork

1. Завантажте [`comfy-deck.zip`](./comfy-deck.zip).
2. У Claude відкрийте **Customize → Skills → + Create skill → Upload a skill**.
3. Завантажте ZIP і ввімкніть скілл. Для генерації файлів має бути ввімкнено **Code execution and file creation**.

Архів має одну кореневу папку `comfy-deck/` з `SKILL.md`, довідковими матеріалами й логотипами. [`comfy-deck.skill`](./comfy-deck.skill) збережено для сумісності з попереднім способом встановлення; його вміст ідентичний ZIP. Для стандартного завантаження в Claude використовуйте `.zip`.

Актуальні інструкції платформи: [використання Skills у Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude).

### Claude Code

Після клонування цього репозиторію виконайте в його корені:

```bash
mkdir -p ~/.claude/skills/comfy-deck
cp -R claude/comfy-deck/. ~/.claude/skills/comfy-deck/
```

Виклик: `/comfy-deck`. Для встановлення тільки в певному проєкті використайте `.claude/skills/comfy-deck/` замість особистої папки. Локальна папка Claude Code сама по собі не встановлює скілл у Cowork; для Cowork використовуйте завантаження ZIP в обліковий запис Claude. Дивіться [документацію Claude Code](https://code.claude.com/docs/en/skills).

### Codex

У корені клонованого репозиторію:

```bash
mkdir -p ~/.codex/skills/comfy-deck
cp -R codex/comfy-deck/. ~/.codex/skills/comfy-deck/
```

Виклик: `$comfy-deck`. Пакет містить `agents/openai.yaml` з описом та іконками для Codex. Автоматичне застосування залишається доступним для відповідних запитів.

## Використання

```text
Зроби 7 слайдів у стилі COMFY про пріоритети кварталу.
Переоформи цю презентацію за брендбуком COMFY 2026, зберігши зміст і числа.
Зроби копію Google Slides і застосуй comfy-deck. Основні шрифти залиш Arial Black і Montserrat.
```

У Codex можна почати запит із `$comfy-deck`, у Claude Code — з `/comfy-deck`. У Claude/Cowork увімкнений скілл застосовується до відповідних запитів.

## Що застосовує скілл

- Основна палітра: зелений `#2ABD13`, помаранчевий `#FC5E0F`, жовтий `#FFFF00`; додаткові рожевий, фіолетовий і зелені з брендбуку.
- Основна та додаткова шрифтові системи з перевіркою українських гліфів. Якщо конкретний рендерер підміняє кирилицю Arial Black, для цих заголовків використовується Montserrat ExtraBold/Black.
- Вибір оригінального логотипу за фоном, збереження пропорцій і форми. Логотип потрібен на обкладинці та завершальному слайді; на інших — відповідно до композиції.
- Правила плюшевої фактури, Пуша, тематичних блоків, меседжбоксів, цін, КРАЩ, «Оплати частинами» й сезонних активів у відповідних сценаріях.
- Збереження нативного тексту, списків, таблиць, діаграм, нотаток і посилань при переоформленні; візуальна перевірка готових слайдів.

Основне джерело: [брендбук 2026](https://www.figma.com/deck/rF8WorMHQHDZvp2dEV8AJ2). Google Drive, Figma та Workvivo ресурси зібрано в [каталозі](./references/resources.md). Шрифти COMFY та додаткова графіка постачаються через посилання, тому доступ до них залежить від облікового запису. Вбудовані тільки оригінальні логотипи. Невизначений блакитний колір не використовується до узгодження кодів у джерелі.

## Вимоги й сумісність

Скілл задає бренд-правила та працює з інструментами презентацій у поточному середовищі. Він не встановлює бібліотеки автоматично. Для нативних Google Slides потрібні підключені інструменти з доступом до презентації. Для PowerPoint потрібен доступний генератор і рендерер. [Особливості середовищ і шрифтів](./references/compatibility.md).

## Структура та складання

```text
SKILL.md                   # Єдине джерело інструкцій
references/                # Брендбук, ресурси, сумісність
assets/logos/              # Оригінальні SVG і PNG
claude/comfy-deck/          # Готова папка для Claude Code
codex/comfy-deck/           # Готова папка для Codex + agents/openai.yaml
comfy-deck.zip              # Завантаження в Claude / Cowork
comfy-deck.skill            # Сумісний архів зі старим розширенням
scripts/build_packages.py   # Синхронізація, складання й перевірка
VERSION
CHANGELOG.md
```

Для супроводу редагуйте кореневі `SKILL.md`, `references/`, `assets/` і Codex UI-метадані. Папки платформ та архіви формуються зі спільних джерел:

```bash
python3 scripts/build_packages.py
python3 scripts/build_packages.py --check
```

Потрібен Python 3.9+; додаткових залежностей для складання немає. Перевірка виявляє розбіжності версій, застарілі копії, неповні ресурси й зайві вкладені архіви.

## Оновлення та версійність

Для Claude/Cowork завантажте актуальний ZIP як оновлений скілл. Для Codex і Claude Code оновіть клон (`git pull`) та повторіть відповідну команду копіювання.

Усі пакети мають одну версію з `VERSION` та `metadata.version` у `SKILL.md`. Історія — у [CHANGELOG.md](./CHANGELOG.md). Політика: **MAJOR** для несумісних змін, **MINOR** для нових можливостей, **PATCH** для виправлень. Релізний Git-тег має формат `vMAJOR.MINOR.PATCH`.

Питання та пропозиції: [GitHub Issues](https://github.com/balabantcev/comfy-deck/issues).
