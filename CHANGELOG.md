# Changelog

Всі значущі зміни до скілу `comfy-deck` документуються тут.

Формат базується на [Keep a Changelog](https://keepachangelog.com/uk/1.0.0/).
Версійність за [Semantic Versioning](https://semver.org/lang/uk/): `MAJOR.MINOR.PATCH`

- **MAJOR** — несумісні зміни в логіці або структурі скілу
- **MINOR** — нові можливості (нові типи слайдів, нові токени) без ломаючих змін
- **PATCH** — виправлення, уточнення інструкцій, дрібні правки

---

## [1.2.0] — 2026-10-13

### Додано
- Правила брендбуку 2026: додаткова палітра, оригінальні активи, Пуш, тематичні блоки, меседжбокси, ціни, КРАЩ, «Оплата частинами» та сезонні сценарії.
- COMFY Semi-Bold, Bold та Ultra-Condensed як додаткові шрифти; Arial Black і Montserrat залишаються основними.
- Каталог пов’язаних Google Drive, Figma і Workvivo ресурсів.
- Готовий пакет `claude/comfy-deck` для Claude Code та `comfy-deck.zip` для Claude/Cowork.
- Правила нативного Google Slides і сумісності шрифтів на основі візуального тесту.
- Відтворюване складання та перевірку пакетів через `scripts/build_packages.py`.

### Змінено
- Узгоджено правила, опис і версію 1.2.0 у спільному джерелі, пакетах Codex/Claude та архівах.
- Оновлено README: встановлення в Claude/Cowork, Claude Code і Codex, приклади застосування та супровід релізів.
- Уточнено вибір логотипу та його недоторканність; вимога логотипу на обкладинці й завершальному слайді однакова в інструкціях та README.
- Перезібрано `comfy-deck.skill` без зайвого вкладеного архіву; він має той самий вміст, що й ZIP.
- Прибрано залежність бренд-правил від конкретної бібліотеки створення презентацій та обов’язкові декоративні картки.

### Уточнено
- У разі підміни українських гліфів Arial Black використовується Montserrat ExtraBold/Black для відповідних заголовків.
- Рекламні правила не застосовуються автоматично до аналітичних KPI та фінансових прогнозів.
- Суперечливий блакитний HEX/RGB не стає офіційним токеном без узгодження джерела.

## [1.0.0] — 2026-06-22

### Додано
- Базова система брендових токенів: Primary `#2ABD13`, Secondary `#FC5E0F`
- Шрифтова пара: Arial Black (заголовки) + Montserrat (текст)
- 7 типів слайдів: title, section divider, stat cards, two-column, icon+text, chart, closing
- Правила фону за типом слайду (зелений / білий / сірий)
- Вбудовані логотипи: `logo-white`, `logo-green`, `logo-mono`
- Правила розміщення логотипу (розмір 1.28×0.29", позиція bottom-left)
- Стилізація графіків під бренд (chartColors, gridLines)
- QA-чеклист для перевірки слайдів
- Інструкція конвертації SVG → PNG для сумісності з PptxGenJS
